# ゲームルール

| 項目 | 内容 |
| --- | --- |
| 版 | 1.0 |
| 関連 | [pieces.md](pieces.md)（駒のデータ）、[spec.md](spec.md)（用語） |

ゲームの規則を、実装とテストの根拠になる粒度で定義する。規則には `R-` の番号を振る。テストは、この番号を参照して書く。

## 1. 構成要素

- **盤**: 16x16 マス。座標は（x, y）で、x は左から右へ 0〜15、y は上から下へ 0〜15。上を北、右を東とする。
- **プレイヤー**: 2〜4 人。人間と AI のどちらも、同じ扱いで 1 席を占める。席は時計回りの順に並ぶ。人数の上限は将来引き上げうるので、人数は定数でなく設定値として扱う（盤の大きさも同様）。
- **駒**: [pieces.md](pieces.md) の種類（数値は `data/pieces.toml`）。盤上の駒は、持ち主・種類・アンカーの座標・向き・現在の HP を持つ。
- **持ち駒**: プレイヤーごとの、種類ごとの個数。
- **情報の公開**: 盤、持ち駒、ドローで引いた 4 枚は、全員に公開される。隠れた情報はない。

## 2. 駒の位置・向き・占有範囲

- **R-01** 向きは北・東・南・西の 4 つ。移動範囲の「前」は向きの方向、「右」は向きに対して右手側。
  - 北: 前 = (0, -1)、右 = (+1, 0)
  - 東: 前 = (+1, 0)、右 = (0, +1)
  - 南: 前 = (0, +1)、右 = (-1, 0)
  - 西: 前 = (-1, 0)、右 = (0, -1)
- **R-02** 大きさ「横x縦」は、向きが北または南のときの値。向きが東または西のときは、横と縦を入れ替える（シャチ 1x2 は、東向きでは 2x1）。正方形の駒は、向きによらず同じ。
- **R-03** 占有範囲は、アンカー（x 最小・y 最小のマス）から、横x縦のマスの長方形。駒の位置は、アンカーの座標で表す。
- **R-04** 常に成り立つこと（不変条件）。
  1. すべての駒の占有範囲が、盤の内側にある。
  2. 異なる駒の占有範囲は、重ならない。
  3. 各プレイヤーの城は、盤上に 0 個または 1 個。
  4. 駒の HP は、1 以上、その種類の最大 HP 以下（HP が 0 になった駒は、その場で盤から消える）。

## 3. ゲームの進行

ゲームは「配置フェーズ → 対戦フェーズ → 終了」の順に進む。

### 3.1 配置フェーズ

- **R-10** 開始時、盤上に駒はなく、各プレイヤーの持ち駒は城 1 個だけ。
- **R-11** 最初の手番のプレイヤーは、ランダムに決める。以降は、席の順（時計回り）に手番が回る。
- **R-12** 配置フェーズでは、手番のプレイヤーが、自分の城を 1 つ置く（ドロー・選択はしない）。全員が置いたら、対戦フェーズへ進む。
- **R-13** 城は、占有範囲が盤の内側に収まり、他の駒と重ならない位置に置く。さらに、他のプレイヤーの城のそれぞれとの間に、3 マス以上のすきまをあける（横方向のすきま、または縦方向のすきまの、どちらか一方が 3 マス以上あればよい）。城の向きは北に固定する。
- **R-14** 配置フェーズの時間切れ（3.3）のときは、R-13 を満たす位置から、ランダムに 1 か所に置く。

### 3.2 対戦フェーズの手番

手番は、次の 3 段階を、この順に行う。

1. **ドロー**: 駒の種類を、重み付きの乱数で、毎回独立に 4 回引く（山札はない。同じ種類が複数出てよい）。引く対象は、出現重みが 0 より大きい種類（城は引かれない）。
2. **選択**: 引いた 4 枚から 1 枚を選び、自分の持ち駒に加える。選ばなかった 3 枚は捨てる。
3. **行動**: 配置・移動・回転のうち、1 つを 1 回だけ行う。行える行動が一つもなければ、パスする。

- **R-20** 選んだ駒は、同じ手番の「行動」で、すぐに配置できる。
- **R-21** 行動の前に、持ち駒に加えた駒を、手番の中で戻したり、選び直したりはできない。
- **R-22** 手番のたびに、脱落していないプレイヤーの席へ、順に手番が回る。脱落した席は飛ばす。

### 3.3 持ち時間

- **R-30** 持ち時間は 1 手番ごとに与える。人間は 60 秒、AI は 20 秒。ドロー（配置フェーズでは手番の開始）から、行動の確定までを数える。
- **R-31** 時間内に行動が確定しなければ、手番を強制的に終える。選択が済んでいなければ、引いた 4 枚からランダムに 1 枚を選んで持ち駒に加える。行動は、パスする。配置フェーズでは、R-14 に従う。
- **R-32** 時間の判定は、サーバーだけが行う。

### 3.4 行動 1: 配置

- **R-40** 手持ちの駒を 1 つ選び、置く位置と向きを選んで、盤に置く。城は、配置フェーズでだけ置ける。
- **R-41** 置いたあとの占有範囲が、R-04 の 1・2 を満たすこと。
- **R-42** 置いた駒の占有範囲のどれかのマスが、自分の駒の占有範囲のどれかのマスと、縦・横・斜めのいずれかで隣り合っていること。
- **R-43** 置いた駒は、選んだ向きで、HP は最大値で盤に置かれる。

### 3.5 行動 2: 移動・攻撃

**移動先の決め方**

- **R-50** 盤上の自分の駒を 1 つ選ぶ。その駒の移動範囲（[pieces.md](pieces.md) の 2 章の部品）から、現在の向きを基準にして、移動量の集まりを求める。移動量を、駒のアンカーに足したものが、移動先のアンカーになる。城は動けない。
- **R-51** 移動先に動いたあとの占有範囲が、盤の内側にあること（R-04 の 1）。他の駒と重なっていてもよい（攻撃になる）。駒が自分自身と重なる部分は、無視する。
- **R-52** 進路にいる駒は、移動を妨害しない（味方・敵を問わず飛び越える）。「直進」の駒だけは、R-53 に従う。
- **R-53** 「直進」の駒は、前方に 1 マスずつ進めたとき、最初に他の駒の占有範囲と重なる位置が移動先になる。他の駒に当たらないときは、占有範囲が盤の内側に収まる限界の位置が移動先になる。1 マスも進めないとき（前が盤の端）は、移動できない。

**攻撃と捕食**

- **R-54** 移動先の占有範囲と重なる駒のそれぞれに、ダメージを与える。ダメージは、（重なったマスの数）×（攻撃した駒の攻撃力）。味方の駒（自分の駒）にも与える。
  - 例: 攻撃力 2 の駒が、象（2x2）の 2 マスに重なれば、象は 4 ダメージ。
- **R-55** HP が 0 以下になった駒は、捕食される。ダメージは、重なった駒すべてに、同時に与える。
- **R-56** 移動先に重なった駒が、すべて捕食されたとき、攻撃した駒は、移動先へ移動する。1 つでも残ったときは、攻撃した駒は動かず、元の位置のまま（ダメージを与えるだけ）。
- **R-57** 攻撃力 0 の駒（城）が、他の駒と重なる位置へ動くことは、ない（城は動けない）。

**捕食した駒の行き先**

- **R-58** 捕食された駒は、盤から消え、攻撃した駒の持ち主の持ち駒になる。成っていた駒は、成ったままの種類で持ち駒になる。持ち駒になった駒は、HP が最大値に戻り、向きは配置するときに決める。
- **R-59** 捕食された駒が城のときは、持ち駒にならず、そのまま消える。城の持ち主は、城がなくなる（5 章）。
- **R-5A** 自分の駒を捕食したときも、自分の持ち駒になる。自分の城を捕食したときは、R-59 により、自分の城がなくなる。

### 3.6 成り

- **R-60** 捕食が 1 つ以上起きたとき、攻撃した駒が成れる種類（`data/pieces.toml` の `promotes_to` を持つ駒）なら、成るか成らないかを選べる。移動したかどうかは問わない。
- **R-61** 成ると、種類が成り先に変わり、大きさ・攻撃力・移動範囲は成り先のものになる。HP は成り先の最大 HP になる。向きとアンカーは、そのまま。
- **R-62** 成り先の占有範囲が、R-04 の 1・2 を満たさないとき（大きくなって盤外にはみ出す、他の駒と重なる）は、成れない。選択肢にも出さない。
- **R-63** 成りの選択は、行動の確定時に、「成る・成らない」を行動と一緒に送る。実際に成りが可能になった（R-60・R-62）ときにだけ、その選択が適用される。

### 3.7 行動 3: 回転

- **R-70** 盤上の自分の駒を 1 つ選び、現在と違う向きを 1 つ選ぶ。1 回の行動で、4 方向のどれにでも向けられる。城は回転できない。
- **R-71** 向きを変えたあとの占有範囲（R-02）が、R-04 の 1・2 を満たさないときは、その向きには回転できない。アンカーは動かさない。
- **R-72** 回転した手番は、移動できない（行動は 1 回）。

### 3.8 パス

- **R-80** 配置できる駒・場所、移動できる駒、回転できる駒が一つもないときは、パスする。パスしても、ドローと選択は行う。時間切れのときも、パスになる（R-31）。

## 4. 駒の移動量の求め方（実装向けの補足）

- 「相対位置」は、指定の（右, 前）を、R-01 の向きの変換で（dx, dy）にしたもの。
- 「範囲」は、前後 a・左右 b のとき、（右, 前）が -b ≤ 右 ≤ b、-a ≤ 前 ≤ a の整数の組すべて（（0, 0）を除く）。
- 「方向と距離」は、方向の単位ベクトルに、min〜max の整数を掛けたもの。
- 「直進」は、R-53。
- 移動量の集まりの重複は、取り除く。

## 5. 脱落と勝敗

- **R-90** 自分の城が盤上から 1 つもなくなったプレイヤーは、脱落する。城を置く前のプレイヤーは、脱落しない。
- **R-91** 脱落したプレイヤーの盤上の駒と持ち駒は、すべて消える。
- **R-92** チームはない。全員が敵同士。
- **R-93** 生き残りが 1 人になった時点で、ゲームは終わり、その人が勝つ。
- **R-94** 1 回の行動で、複数のプレイヤーの城が同時になくなったときは、同時に脱落する。生き残りが 1 人ならその人の勝ち。0 人なら、全員が引き分け。
- **R-95** 対戦フェーズの手番が、（開始時の人数）×100 回に達したら（途中で脱落者が出ても、上限は変わらない）、ゲームを終える。残っている城の HP が最も大きいプレイヤーが勝つ。同じ値なら、同点の全員が引き分け。脱落済みのプレイヤーは、生き残りより下位。
- **R-96** プレイヤーは、いつでも投了できる。投了すると、脱落する（R-91 と同じ）。
- **R-97** 順位は、生き残りを上位（R-95 の場合は城の HP の順）、脱落した人を、脱落が遅い順に並べる。同時に脱落した人は、同順位。1 位が勝者（同順位が複数なら、引き分け）。

## 6. 状態遷移（全体図）

```
待機（ルーム）
   │ 開始
   ▼
配置フェーズ ── 全員が城を置いた ──▶ 対戦フェーズ
                                         │
                      ┌───────────────────┤（手番ごとに繰り返す）
                      ▼                   │
               ドロー → 選択 → 行動（配置/移動/回転/パス）
                      │
                      └─ 脱落・投了・手番数の上限で、生き残り 1 人以下 ──▶ 終了
```

## 7. 例

**例 1: 象が小馬を攻撃し、成る**
子供象（攻撃力 1）が、HP 1 の小馬と重なる位置へ動く。ダメージは 1×1 = 1 で、小馬は HP 0 になって捕食される。小馬は持ち駒になり、子供象は移動先へ移動する。成れる種類（象）なので、成るか成らないかを選べる。成り先の象は 2x2 なので、移動先から右・下の 2x2 が盤内で空いていれば、成れる。成ると、HP は 8（象の最大値）になる。

**例 2: 倒しきれない攻撃**
攻撃力 2 の馬が、HP 8 の象に重なる位置へ動く。ダメージは、重なったマス数が 1 なら 2。象の HP は 6 になるが、残っているので、馬は動かない。馬は元の位置に残る。

**例 3: 同時脱落**
象（2x2）が、2 人の城（それぞれ 2x2）の両方に重なる位置へ動き、どちらも HP 0 になったとき、2 人は同時に脱落する。残りが 1 人なら、その人が勝つ。

## 8. 危険な駒の判定

画面の「！マーク」と、AI の評価に使う判定。実装は `rules` の `threats`。

- **R-A0** 駒 X が「危険」とは、X の持ち主以外の、脱落していないプレイヤーの駒 Y が、1 回の移動（R-50〜R-54）で X に与えるダメージが、X の現在の HP 以上になる移動先を持つこと。
  - ダメージは、実際の攻撃（R-54）と同じ計算（重なったマス数 × 攻撃力）。
  - 手番、手番の段階、持ち主の席の並びは見ない。配置は攻撃ではないので、含めない。成りや、その後の手は考えない。
- **R-A1** 危険な駒ごとに、その駒を 1 回の移動で捕食できる、攻撃側の駒の一覧も求める。
- **R-A2** 同じ持ち主の駒は、危険の原因にならない（味方への攻撃は、捕食であっても、危険とは見なさない）。
- 判定は、`apply` が実際に起こす捕食と一致する（捕食されない駒は危険でなく、危険な駒は、ある行動で実際に捕食される）。

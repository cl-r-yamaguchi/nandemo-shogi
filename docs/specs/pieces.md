# 駒の仕様

| 項目 | 内容 |
| --- | --- |
| 版 | 2.0 |
| 関連 | [game-rules.md](game-rules.md)（ルール）、[architecture.md](architecture.md)（データの置き場所） |

駒の数値（大きさ・攻撃力・HP・出現重み・成り先・移動範囲）は、[`data/pieces.toml`](../../data/pieces.toml) が**唯一の定義**。この文書には、数値を書かない（同じ知識を 2 か所に置かないため）。この文書は、駒の設計の意図と、データの書き方を説明する。

駒を追加・調整するときは、`data/pieces.toml` だけを直す。ルールのコードは変えない。

## 1. 駒の一覧

| id | 名前 | 役割 |
| --- | --- | --- |
| castle | 城 | 守るべき駒。2x2 の大きさで、動かず、攻撃力は 0。1 人 1 つ。ドローでは引かれない |
| kid-elephant | 子供象 | 周囲 8 マスに動ける小さな駒。捕食して成ると、象になる |
| elephant | 象 | 2x2 の大きな駒。5x5 の範囲に動ける重量級 |
| foal | 小馬 | 桂馬の動きで、駒を飛び越えて攻める。捕食して成ると、馬になる |
| horse | 馬 | 2 マス離れた外周に飛ぶ長距離の駒 |
| kid-lion | 子供ライオン | 前に 1 マスだけ動ける。捕食して成ると、ライオンになる |
| lion | ライオン | 周囲 8 マスに動ける、一撃が重い駒 |
| orca | シャチ | 1x2 の大きさで、前後に長い範囲を攻める。成りなし |
| baby-penguin | 赤ちゃんペンギン | 前に 1 マスだけ動ける。捕食して成ると、ジェットペンギンになる |
| jet-penguin | ジェットペンギン | 前方に一直線に突進する奇襲役。途中で止まれない |
| bear | クマ | 前後左右に 1 マスずつの、頑丈な壁役 |
| deer | シカ | 斜めにだけ、1〜2 マス動ける機動役 |

- 子供の駒は出現重みが大きく（出やすく）、大人の駒は小さい（出にくい）。大人の駒は、子供が捕食して成ることでも得られる。
- 成りがあるのは、子供から大人の 4 組だけ（子供象→象、小馬→馬、子供ライオン→ライオン、赤ちゃんペンギン→ジェットペンギン）。成りのルールは [game-rules.md](game-rules.md) の 3.6。
- クマ・シカ・ジェットペンギンの数値は初期値で、遊びながら調整する。

### 設計の意図

- **クマ**: 攻撃力が高く HP も多い壁役。動きは遅い（十字に 1 マス）が、倒すのに手間がかかる。
- **シカ**: 斜めにしか動けない機動役。ほかの駒と動く軸が違うので、囲まれにくい。
- **ジェットペンギン**: HP は低いが、一直線に長距離を詰める奇襲役。赤ちゃんペンギンが、捕食して成る先。
- **子供象と子供ライオン**: 周囲 8 マスに動ける子供象は、成ると大きく重い象になる。前にしか進めない子供ライオンは、成ると一撃が重いライオンになる。同じ「小さい駒」でも、成ったあとの役割が違う。

## 2. データの書き方

`data/pieces.toml` に、`[[piece]]` を 1 駒 1 つ書く。

| 項目 | 意味 |
| --- | --- |
| `id` | 駒の識別子（重複不可）。`castle` は、ルールが特別に扱う |
| `name` | 表示名 |
| `size` | 大きさ `[横, 縦]`（向きが北のときの値。1 以上） |
| `attack` | 攻撃力 |
| `hp` | 最大 HP（1 以上） |
| `weight` | ドローでの出現重み（0 は引かれない。1 つ以上の駒が 1 以上） |
| `promotes_to` | 成り先の `id`（省略すると成らない） |
| `movement` | 移動範囲の部品の並び（省略すると動かない） |

読み込み時に、`id` の重複、存在しない成り先、不正な大きさ・HP・移動範囲を検査し、エラーで拒否する。

### 移動範囲の部品

移動範囲は、次の 4 種類の部品の組み合わせで宣言する。座標は、駒の向きを基準にした「（右, 前）」。向きが北なら、右は東（x が増える向き）、前は北（y が減る向き）。大きい駒は、アンカー（左上のマス）を基準にして、全体が平行移動する。移動量（0, 0）は含まない。

| 部品 | 意味 | 書き方 |
| --- | --- | --- |
| 相対位置 | 指定した移動量へ動ける | `offsets = [[右, 前], ...]` |
| 範囲 | 前後に最大 a、左右に最大 b の長方形の、どの移動量へも動ける（斜めを含む） | `rect = { front = a, side = b }` |
| 方向と距離 | 指定した方向に、最小〜最大の距離のどの移動量へも動ける | `rays = [{ dir = "front", min = 1, max = 2 }, ...]` |
| 直進 | 指定した方向へ、他の駒に当たるまで、または盤の端まで進む。途中で止まれない | `charge = "front"` |

- 方向は、`front`・`back`・`left`・`right`・`front-left`・`front-right`・`back-left`・`back-right`。
- 「相対位置」「範囲」「方向と距離」は、間にある駒を飛び越える（進路は妨害されない）。直進だけは、最初に当たる駒で止まる（[game-rules.md](game-rules.md) の R-53）。
- 駒を追加するときは、まず上の部品で表せるか確認する。表せない動きが必要なときだけ、部品を足す（足すときは、[game-rules.md](game-rules.md) と `rules` の実装も更新する）。

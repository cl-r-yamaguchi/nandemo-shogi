## 2. 目的とゲームの概要

**目的**: 友人と、ブラウザで気軽に遊べる、ポップな 3D の陣取り・食い合い対戦ゲームを作る。将棋の「取った駒を持ち駒にして使う」仕組みと、駒ごとの HP・攻撃力による殴り合いを組み合わせる。

**ゲーム**: 16x16 の盤で、2〜4 人（人間と AI の混在可）が、時計回りに手番を回す。

1. 全員が順番に、自分の「城」を盤に置く。城がなくなると負け。
2. 以降、手番ごとに、駒を 4 枚引いて 1 枚を選び、持ち駒にする。そのあと、駒の配置・移動・回転のうち 1 つを行う。
3. 駒は、移動先にいる駒にダメージを与える。HP が 0 になった駒は「捕食」され、捕食した人の持ち駒になる。
4. 城を失った人は脱落し、最後の 1 人が勝つ。

**遊び方の特徴**
- 駒は向きを持ち、移動範囲は向きに対して決まる。向きを変えること自体が 1 回の行動になる。
- 味方の駒も攻撃でき、進路は誰にも妨害されない。守りは「置き方」と「間合い」で作る。
- ドローは運だが、4 枚から選べる。選ばなかった 3 枚は捨てる。
- 隠れた情報はなく、ドローの結果や持ち駒は全員に見える。

**動作環境**: 当面は、ローカルホストで動かし、同じ PC の複数のブラウザ・タブから同時に遊ぶ。外部公開しても遊べる設計にしておく（[online.md](online.md)、[architecture.md](architecture.md)）。

## 3. 用語

| 用語 | 意味 |
| --- | --- |
| 盤 | 16x16 マスの正方形の盤 |
| 駒 | 盤に置くもの。種類ごとに、大きさ・攻撃力・HP・移動範囲を持つ |
| 城 | 各プレイヤーが最初に置く駒。すべてなくなると脱落 |
| 持ち駒 | プレイヤーの手元にあって、配置できる駒 |
| 向き | 駒が向いている方向。北・東・南・西の 4 つ。移動範囲の「前」の基準 |
| 占有範囲 | 駒が盤上で占めるマスの集まり。大きさと向きで決まる |
| アンカー | 占有範囲の左上のマス。駒の位置と移動量の基準 |
| 配置 / 移動 / 回転 | 手番で選べる 3 つの行動 |
| 攻撃 | 移動先に重なる駒へダメージを与えること |
| 捕食 | 駒の HP が 0 になって盤から消え、攻撃した人の持ち駒になること |
| 成り | 捕食したときに、子供の駒が大人の駒に変わること |
| ドロー | 手番の最初に、駒を 4 枚引くこと |
| 脱落 | 城がすべてなくなって、ゲームから外れること |
| 席 | 手番の順に並んだプレイヤーの位置。人間も AI も 1 席を占める |
| ルール（リクエスト） | 対戦を始めるための設定（人数・AI の強さ）。「ゲームルール」とは別物 |
| ルーム | 同じ対戦に参加するメンバーが待機・対戦する場 |
| 手番番号 | 対戦フェーズの開始からの手番の通し番号（0 始まり） |

## 4. 対象外（やらないこと）

- 外部への公開、認証・アカウント、ランキング・レーティング
- 観戦、チャット、フレンド機能
- 音（BGM・効果音）
- 日本語以外の言語
- サーバー再起動をまたぐ対局の復元（記録の保存は行う）
- スマートフォン向けに最適化した画面（タッチ操作には対応する）

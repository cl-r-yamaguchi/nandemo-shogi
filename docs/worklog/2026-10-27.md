# Issue #30: server: WebSocket の通信（`feature/30-server-websocket`）

PR #29 マージ後に着手。axum で WebSocket の入口を作り、ロビーへ振り分ける。

## やったこと

- `server` に、WebSocket の通信を実装した。
  - `ws.rs`: axum の入口（`/ws`）。オリジンの検証（許可に含まれない、またはない接続は 403）、同時接続数の上限（503）、通信の層でのメッセージの大きさの上限、最初の `hello` の待ち時間（10 秒）、テキストのみ、検証（`decode_client`）、拒否の返信。
  - `hub.rs`: 接続の管理（プレイヤー ID ごとに 1 接続。新しい接続が古い接続を置き換える）、ロビーへの振り分け、結果の配送（詰まった遅い接続は切る）、時計の駆動（250 ミリ秒ごとの `tick`）、AI の駆動（計画 → 別スレッドで考える → 最低 1.5 秒の間を置いて反映。同じルームで重ならない）。
  - `rate.rs`: 送信頻度の制限（トークンバケット: 一度に 30 件、毎秒 10 件）と、不正が続いたときの打ち切り（8 回）。
  - `main.rs`: 設定を読み込んで待ち受ける。接続・対局の開始と終了・拒否をログに出す（プレイヤー ID・表示名は出さない）。
  - `config.rs`: 同時接続数（`NANDEMO_MAX_CONNECTIONS`）と AI の間（`NANDEMO_AI_DELAY_MS`）を追加。
- テストは `server` 109 件（頻度の制限、オリジンの照合、接続を模した窓口でのハブ、本物の WebSocket を通した通し: オリジン・503・`hello`・不正な入力・頻度超過・対局の開始・城の配置・再接続・置き換え）。
- 実行ファイルを起動して、`curl` で、許可されたオリジンは 101、許可されないオリジンは 403 になることを確認した。
- `CLAUDE.md`・`architecture.md`・`online.md` を更新した。

## 判断とその理由

- ハブは、通信の形（WebSocket）に依存しない。接続は、送信口（`mpsc`）を持つ窓口として扱う。通信なしで、振り分け・配送・置き換え・遅い接続の切り離しを、テストできる。
- ロックは、短く持つ（メッセージごとに完結）。AI が考える間は、ロビーのロックを手放す（計画 → `spawn_blocking` → 反映）。
- 接続の送信口は、大きさに上限を設けた有限の送信口。読まない遅い接続が、メモリを食い続けないようにするため。詰まったら、その接続を切り、ロビーに切断を知らせる。
- 古い接続からのメッセージは、無視する（接続の番号で照合）。置き換えられた古い接続が閉じても、新しい接続の切断にならない。
- `Origin` がない接続も拒否する。ブラウザは、WebSocket の接続に、必ず `Origin` を付けるため。ブラウザ以外のクライアントが `Origin` を偽ることは防げないが、ローカル限定・認証なしの前提では、ブラウザ経由の、別のサイトからの接続（クロスサイトの乗っ取り）を防ぐことが目的。
- プレイヤー ID は、ほかのプレイヤーに送るメッセージ（席・通知）に含めない。ID を知っている人だけが、その席に戻れる。

## レビュー（`/code-review`）の反映

- 詰まった接続や、置き換えられた古い接続が、実際には閉じられない問題を直した。接続ごとの「閉じる合図」（`Notify`）をハブが持ち、読み込みの側が、それを待つ。送信口を手放すだけでは、読み込みの側が閉じないため。
- Ctrl-C で、接続が残っていると終了が待たされる問題を直した。`Hub::shutdown` が、全接続に合図を送ってから、サーバーが終わる。
- `hello` を送らない通信路が、接続数の上限に数えられない問題を直した。通信路を開く時点で数える（`try_open_socket`、手放すと減る）。
- 無通信・半開きの接続が残る問題を直した。30 秒ごとに ping を送り、何も届かないまま 90 秒たったら閉じる。通信の層で拒否された大きすぎるフレームにも、理由（`too_large`）を返す。
- 頻度超過に、サイズ超過の `too_large` を使っていたので、専用の `rate_limited` を足した（TypeScript の型も再生成）。
- AI の思考が異常終了したときは、手番を強制的に終える（同じ失敗を、250 ミリ秒ごとに繰り返さない）。配送を 8 周で打ち切って、メッセージを捨てる問題を直した（1 周ごとに必ず接続が減るので、尽きるまで続けても終わる）。`NANDEMO_MAX_CONNECTIONS=0` を拒否する。
- プレイヤー ID が、秘密であることを、`online.md` に明記した（認証は対象外）。
